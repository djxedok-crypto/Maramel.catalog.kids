Откройте index.html в браузере. Файл style.css должен лежать рядом.

В папку images добавьте фотографии:
classic-background.jpg — фон программы Дед Мороз + Снегурочка + персонаж;
classic-characters.png — фото 3/4 персонажей;
merry-background.jpg — фон Merry Christmas;
merry-characters.png — фото Санты, Мисс Клаус, двух эльфов и Гринча;
frozen-background.jpg — фон Холодного сердца;
frozen-characters.png — фото пяти персонажей;
roblox-background.jpg — фон Roblox;
roblox-characters.png — фото четырёх персонажей;
logo.png — логотип (если есть готовый файл; пока используется текстовый логотип).

Если фото персонажей ещё не готовы, карточки покажут аккуратную заглушку. Если фоновые фото не добавлены, останутся яркие цветные градиенты.

Все цены указаны за 1 час программы. Видимость секций можно переключать:
data-visible="true" — показывать; data-visible="false" — скрывать.
Контактная ссылка WhatsApp внизу пока универсальная https://wa.me/ — замените её на номер агентства в международном формате без плюса и пробелов.
